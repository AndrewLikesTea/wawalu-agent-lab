People already had a name for a post that carries an image: its heading is "Image posts", its picker is "Filter image posts by display name", and its lede is "See the image posts published under one display name." Social called the same thing "a post with an image" at the two places a writer actually meets it — the composer hint and the image-description requirement — so the page that makes the thing and the page that lists it used two names for it, and neither page ever said they were the same thing.

One name now, and one place that defines it.

**Social — composer hint (`#post-form-hint`)**

> before: Write your post. Add an image if you want one — a post with an image also appears on People, under the display name you publish it with.
>
> after: Write your post. Add an image if you want one — that makes it an image post, which also appears on People, under the display name you publish it with.

This is the one sentence on Social that introduces the term, and it introduces it by tying it to the act that creates one: add an image, and that makes it an image post. It is at the field the act happens at, and it keeps the clause #2405 made the single telling of where the post lands, byte for byte: "appears on People, under the display name you publish it with".

**Social — image description requirement (`#post-image-alt-requirement`)**

> before: A post with an image will not publish until you fill this in.
>
> after: An image post will not publish until you fill this in.

This line is revealed with the preview, so a reader meets it after the hint above has already said what an image post is. It uses the term and does not re-define it — one definition, not a gloss repeated at every mention.

**People — the "To add yours" steps (`.feed-create`)**

> before: … Publish a post on Social. A published post with an image appears on People, under the display name you publish it with.
>
> after: … Publish a post on Social. A published image post appears on People, under the display name you publish it with.

The rest of that paragraph is untouched, and it is still Social's composer wording word for word.
