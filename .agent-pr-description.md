Prompt coach now uses one name for each number it shows (#2344). This is a wording-only change: no scores, weights, cutoffs, layout, or comparison logic changed.

## Terms

| Concept | Term used everywhere | Shown as |
| --- | --- | --- |
| The 0–100 result for a prompt | **overall score** | `56 / 100` |
| Intent, Efficiency, Model fit (each 0–100, weighted 50/30/20) | **component scores**, one each: **Intent score**, **Efficiency score**, **Model fit score** | `Intent score · 50% of the overall score` → `28 / 100` |
| The A–F band the overall score falls in | **letter grade** | `grade F` |
| The two sides of a revision comparison | **Previous prompt · overall score** / **Revised prompt · overall score** | `56 / 100 · grade F` |

"Grade" stays as a verb ("Grade this prompt", "Delete prompt and grades"). It no longer names the number. The comparison's baseline is "previous", not "original": after a third grade, the baseline is the second prompt.

## Tests

Existing assertions that pinned the old strings now pin the new ones, and none were deleted. The new `tests/prompt-coach-score-terms.test.js` loads coach.html in the browser harness and waits for the script-painted state, not authored text. It checks that the painted bundled example shows `Overall score` and `Letter grade`, and a toggle that names 3 component scores. Each component label must match `<Intent|Efficiency|Model fit> score · N% of the overall score`. It then grades a visitor prompt and checks the same labels. After a revision it checks the comparison rows, their aria-label, and the component-score panel. In both states, no text in the coach region may say "three scores", "both scores", "Prompt score", "Grade band", "subscore", or "its/this/last/revised grade".

## Deeper UX problems found, not fixed

- **Two renderers for one result.** The bundled example is drawn by `coaching-result-presentation.js` + `coaching-result-view.js`. A visitor's own grade is drawn by `prompt-coaching-view.js`. They now use the same terms, but each string is written twice, so they can drift again. The layouts also differ: the example shows labelled facts (Overall score / Letter grade), while a visitor's result shows a sentence ("Overall score: 56 / 100 · grade F. D starts at 60: 4 points away."). Unifying them is a redesign, so it is out of scope here.
- **The comparison's delta line is unlabelled.** "+33 points · 56 → 89 of 100." sits right under the two labelled overall-score rows, so it reads correctly in place. It comes from `prompt-revision-comparison.js` and never names the overall score itself, so it loses that meaning in the copied summary's "Change:" line. The comparison never mixes overall and component numbers in one row. Component scores only appear in their own disclosure.
- **"Grade" still names two different things.** It is the verb for the action and part of "letter grade". The reset button "Delete prompt and grades" (#2341) uses it for the results. It was left as is, because it names results, not a number.
