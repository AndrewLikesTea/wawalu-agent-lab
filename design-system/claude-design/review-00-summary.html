wawalu.org — UX review

from live production screenshots (desktop light/dark + 390px mobile) · each finding has a card with a proposed fix

01

Mobile: category bars vanish & chips clip. .cat-row's fixed 5-column grid has no responsive rule — the bar track collapses to ~0px at 390px.

high
02

Token chart says almost nothing. Cache reads are structurally ~99% of tokens, so a linear axis flattens input/output/cache-create into invisibility.

high
03

Views and person filters look identical. "michael.albada" sits in the same tab row as "overview" — reads as a page, and two tabs appear selected at once.

high
04

Topic titles wrap one word per line. 110px title column forces 5-line titles; huge cards, poor scanning.

medium
05

"new" delta-chip noise. When every category is new the chip repeats 4× and reads as a button.

medium
06

No URL state. Tab, person, and time range live in React state only — refresh resets, nothing is shareable or deep-linkable.

medium
07

Global range toggle lies. 1h/24h/7d stays prominent on connect / organization / admin where it does nothing.

medium
08

Weak affordances on Connect. "Set up browser extension" renders as bare text next to a filled primary — invisible as an action.

medium
09

Destructive "archive" sits beside "save details". Equal visual weight, no confirmation, one slip archives a group.

medium
10

Verdict placeholder is a large empty banner. "reading the day's activity…" holds a full-width card hostage while the LLM writes.

low
11

Category colors aren't reused on Topics. Overview gives each category a color; Topics shows plain gray ALL-CAPS badges — a missed scanning aid.

low
12

Wordmark undersells the product. "claude telemetry" — it now captures Codex, ChatGPT and Gemini too.

low
